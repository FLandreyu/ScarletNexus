# P6 分析、数据迁移与部署准备

依据总纲3.1、4.2、P6。沿用Vue/Java21/MyBatis/PostgreSQL模块化单体；不运行真实模型、不生产部署、不修改已有迁移或用户.env.example。GraphFlow工具未提供，按AGENTS规则定向检查，不能声称已context/plan/index。

## 分步门禁

1. 学习分析：真实学习时长、任务/路线完成、自报与规则证据分开、独立正确率、技能与日期趋势、可追溯能力评估。明确日期/时区/分母/零数据，按当前用户隔离；PG API及桌面/手机验证。
2. JSON导出/导入：学习记录导出与可迁移知识目录格式明确分开。目录导入先校验预览、再明确确认；新UUID、新技能，不覆盖既有节点/图谱/学习证据；非法引用/分类环/先修环/重复输入拒绝，事务与幂等。不能将目录导入冒称全部学习历史恢复。
3. 完整备份恢复：数据库pg_dump与私有附件共同备份，完整性清单、隔离恢复、新实例读取与checksum验证；不在用户真实数据库运行恢复，不删原卷。JSON学习快照不是数据库/附件备份的替代品。
4. 运维与安全：监控健康、结构化脱敏日志/轮转、生产TLS/Secure Cookie/最小权限/限流/资源限制说明与独立配置；鉴权/附件隔离、依赖与镜像风险复核、桌面手机全旅程。

各步实现、测试、提交并维护PROGRESS；P6全部门禁通过前不标记阶段完成或开始P7。第一批先落实分析、当前用户学习快照导出与知识目录迁移，不把后续恢复/生产安全工作标为完成。

## 指标合同 v1

- 输入为起止本地日期（含首尾）、IANA时区、可选技能。默认最近30天，最长366天；查询范围转换UTC。技能过滤必须属于当前用户。
- 时长仅统计ENDED时段的服务器accumulated_millis，按ended_at归入日期；不把暂停/进行中的计时算成已完成时间，也不伪造跨日细分。该口径不能回答逐分钟活动时间。
- 任务完成率：范围内created_at创建的任务中，DONE/(TODO+DOING+DONE+DEFERRED)，取消单列且不进分母；当前状态回看，不是历史状态重建。
- 作答：按created_at计入，独立来自提交时曝光快照。每次作答仅取最新RULE复核为客观比对；独立正确率=独立且RULE CORRECT/独立且RULE有明确CORRECT或INCORRECT；UNSURE/无规则复核单列，自评不加入。重复复核不能重复计一次作答。
- 路线完成：当前有效选择的必修节点自报COMPLETED/必修总数，单独标注，不视作能力。能力按节点分别取最近RULE和SELF评估，保留level/confidence/time/evidenceIds；不把自评与验证折叠成百分比。
- 图表和明细来自同一API真实数据，空分母显示“暂无可比结果”。返回generatedAt和口径说明。

## 数据迁移边界

学习快照格式`scarlet-nexus-learning-snapshot/v1`：只读导出当前用户业务表JSON，含学习文本/题目答案，用户界面提醒敏感性；不含users/password/session/CSRF/Key，附件仅元数据与校验和、不含磁盘路径/二进制。按用户行锁获取一致业务切片，超出上限明确拒绝，不静默截断；纯文本下载、no-store。

知识目录格式`scarlet-nexus-catalog/v1`：节点定义与跨技能位置/关系分开，保留共享节点；1..100技能、最多1000节点/3000关系。严格字段、类型、UUID、长度与引用/环校验。导入预览存服务器验证后的草案，返回数量与新增范围；明确确认后事务新建全部UUID，保留旧→新映射和来源hash，不接受覆盖或服务端owner字段。归档状态保留。目录中的URL/文本不执行、不抓取。不含路线/学习/AI记录，完整恢复走备份演练。
