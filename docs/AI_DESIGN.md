# AI 系统设计

状态：AI部分仍为设计，未实现Provider、未发送外部模型请求。P2已实现手动草案、严格v1结构与图校验、预览确认及事务发布；这些是未来AI输出的审核边界，不代表AI生成已实现。AI为可选能力；不得把未配置状态伪装为生成成功。

## 服务边界

`AIProvider` 提供 generateStructured、chatStream、analyzeImage、estimateUsage，另提供 capabilities（结构化、流式、图像）；请求包括受控模型名、版本化 prompt/schema、deadline 和 user/job ID，返回内容、终止原因、用量来源及可恢复错误。首个真实适配器采用可配置 OpenAI-compatible HTTP 协议，P2 在正式文档核对后实施；Fake Provider 只在 src/test。

配置：base URL、model、Key、timeout、有限重试与预算。Key 只在服务端注入；不从浏览器传给供应商。初期配置走环境变量，不在设置页返回明文密钥。模型能力不支持图片时返回明确错误或用户选文本输入，不偷偷替换解释。无 Key 仅返回 AI_NOT_CONFIGURED，手动功能照常工作。

## 生成与教学流程

- 图谱/路线：目标背景 → 版本化 JSON schema → 引用、重复候选、分类环、先修环校验 → 草案 → 人工修改 → 变更预览 → 明确确认 → 数据库发布事务。无论模型声称多完整，都只是候选。
- 教学上下文：从 DB 读取当前用户目标、节点、路线位置、先修、最近相关证据、偏好、必要对话；裁剪先删低相关历史，始终保留提示等级和安全约束。记录 token 估计与截断标记。
- 作答：先保存内容，后请求批改；题目/答案权限分离。提示等级 NONE、FIRST_ERROR、ONE_STEP、FULL_EXPLANATION 由请求和会话练习模式限定，独立模式不提供答案。批改可为 UNCERTAIN / NEEDS_REVIEW，用户复核后生成证据，不直接升级能力。
- 计划：确定性规则先校验可用时长、冲突、依赖、到期复习，AI 只建议内容；未确认不影响正式任务。

## 超时、成本与安全

初始连接超时5s、总体60s、最大结构化修复2次；仅对明确可重试的429/502/503有限退避，遵守 Retry-After。流式中断不自动重发整个请求。生成任务保存失败原因、已有草案和 requestId，可显式重试；收费不确定时标记 UNKNOWN，不能假设未计费。模型调用在数据库事务之外。

预算在发请求前按用户/日原子预留上界，结束后按供应商用量结算；缺失用量标记 ESTIMATED，价格必须来自配置并带币种和更新时间。不硬编码虚假的成本/准确率。预算未配置时默认禁用外部调用，启用真实供应商/付费调用需用户授权。

结构化结果不作 SQL/脚本/HTML 执行；外部资料放入明确不可信数据边界；禁止模型获得数据库凭证/任意工具权限。日志不写完整 prompt、密钥、附件。模型无法绕过所有权校验、用户确认、乐观锁与事务。无初始向量库；必要时另做 ADR。

P2 测试：非法 JSON、缺字段、引用错误、环、重试耗尽、发布回滚、并发冲突、Provider 未配置。P4 增加 SSE 中断、超时不丢作答、提示等级、图像能力降级与附件权限。真实 Provider 联调仅在授权且本地安全配置 Key 后执行，Fake 测试不算真实联调。
