# P4 导师、练习与证据

依据总纲3.3、4.3、5、P4，继续Java21/Spring/Vue模块化单体。GraphFlow工具当前未提供，按项目约定定向检查，不声称context/plan/index已执行。

## 验收标准

1. 题目/作答持久化，独立练习读取不包含答案或隐藏提示；先提交不可变作答，再请求分级提示。提示或解析曝光记录影响之后的独立性标记，不修改历史作答。
2. 支持精确文本规则比对及人工复核证明题；不确定明确UNSURE。批改/复核追加历史，确认后才生成关联证据；自评与规则比对分开标记，规则评估保守且可解释，不凭一次答对判L5。
3. 图片上传须经过体积/像素/magic/解码/重编码，私有存储及随机键，下载检查本人归属，失败不产生可下载文件。图片无法由模型理解时明确降级，允许手动转录，不伪造识别结果。
4. KaTeX仅渲染数学片段，其他文字按文本展示，trust=false，不执行HTML或宏命令。
5. 节点/练习关联对话，真实供应商SSE增量传输，用户内容先落库，截断/超时/断线保留内容和状态；重试为新确认请求，不自动重发付费请求。受限提示使用题目作者保存的明确提示，不能把未审查模型长文本当作受限提示直接播放。
6. AI上下文有界，来自本人节点/路线/目标/先修/证据/近期对话。共享P2每日token与货币额度；任务价格快照、未知计费保守占用、过期任务显式恢复；外部网络不占用数据库事务。
7. 无AI配置仍能完成练习、图片留档、人工复核、证据及自评。真实PG/API、桌面/手机浏览器、本地HTTP流协议验收，不用本地协议冒充真实模型质量。新增真实模型调用需要单独授权。

## 设计决策

问题、作答、批改与证据以稳定UUID关联；答案仅服务端用于规则比对/显式查看解析，不在列表或独立作答API泄露。新作答追加，明确幂等键避免重复提交。精确文本不适用于证明题，证明题默认UNSURE并由用户复核，人工意见始终标记SELF_REVIEW。

提示级别为NONE/ONE_HINT/FULL_SOLUTION；ONE_HINT返回作者准备的提示；FULL_SOLUTION需明确确认并记录曝光。其他教学模式如苏格拉底讲解属于导师对话，不承诺自动判定“首个错误”。严格受限提示不直接播放无法证明安全的模型输出。练习对话须关联已有作答；通用节点讨论与独立练习为不同上下文。

能力等级L0–L5。SELF评估可选等级但必须有证据/理由，可信度LOW；RULE只依据确认后的规则比对证据，最多L2，区分自报独立/提示后结果。所有评估追加历史、显示依据；不生成伪精确百分比。

图片原件只进隔离处理，输出重新编码PNG、丢弃元数据，不执行SVG/HTML，不抓取远程链接。数据库保存任务/作答引用、校验和与状态；文件仅随机键，归档优先；附件不自动进入模型请求。

导师对话新增独立运行记录，不创建虚假的图谱草案来复用旧job外键。复用价格策略及每日token/货币账本，单次费用快照关联导师运行。原P2图谱生成合同不变。无新AI SDK或服务；现有Java适配器扩展真实Chat SSE能力。图片分析能力未启用时明确返回不支持。

## 交付顺序

练习/复核/证据/评估 → 图片隔离与数学渲染 → 导师持久化/SSE/预算 → 本地PG/API/浏览器/协议验收。每个切片记录实际证据；未通过的门禁不标记完成、不进入P5。
