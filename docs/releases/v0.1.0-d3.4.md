# Scarlet Nexus 0.1.0-d3.4 Windows 桌面预览版

面向 Windows 11 x64 的离线安装包。安装完成后，从桌面 Scarlet Nexus 图标打开独立窗口，首次启动创建自己的登录账号。

## 本版功能

- 内置 Java 25 和 PostgreSQL 17 运行时，支持离线首次设置与手动学习业务。
- 技能与知识树、草案审核发布、目标与学习路线、任务计时和笔记。
- 练习作答、一步提示、规则比对、私有图片、计划复习、分析和 JSON 数据管理。
- 当前用户安装、桌面与开始菜单快捷方式、持久学习目录和升级前加密备份。
- d3.4 提供向独立新配置恢复升级备份的维护入口，操作见随附恢复说明。

## 下载与使用

下载 `ScarletNexus-0.1.0-d3.4-windows-x64-setup.exe`，安装后从桌面启动。安装包为312021752字节，SHA256如下。

```text
01932a1d2151ab34c4edaa7f8150b689dce319f124b10bf1465d1c6c0703d7d8
```

发行附件提供 `SHA256SUMS.txt`、中文使用与恢复说明、第三方许可证归档及包内容核对记录。

学习数据默认保存在 `%APPDATA%\ScarletNexus\learning`。完整保管该目录时应包含数据库、附件、升级备份和 `secrets`。恢复加密备份需要对应密钥，登录密码不能代替该密钥。首次设置密码至少12个字符，请自行保管。

AI功能需要另行配置模型服务，当前默认生成未启用，手动业务可离线运行。更新采用下载完整安装包的方式。
