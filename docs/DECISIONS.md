# 架构决策记录

## ADR-001 — 保持指定栈，采用模块化单体（2026-11-15）

采用 Vue 3 / Java 21 / Spring Boot 3.5 / MyBatis / PostgreSQL；不引入微服务、Redis 或向量库。原因：单用户产品需要可靠数据关系和可备份性，单体足够且易维护。属于总纲明确默认值，不构成架构变更。

## ADR-002 — 会话认证与同源代理

采用服务端会话 + HttpOnly/SameSite Cookie + CSRF；P1 使用 PostgreSQL 持久会话。避免客户端长期 token 生命周期复杂度。P0 先拒绝所有私有入口，不生成默认账号。Nginx 本地入口、生产 TLS 留给 P6。

## ADR-003 — 迁移按阶段扩展

目标 ERD 全量设计，P0 只迁移 users 和 audit_events。后续业务表随真实约束、代码和测试一起迁移，避免在尚无功能时冻结未经验证的结构。P0 不插入学习样本、管理员或掌握度。审计追加由 PostgreSQL 触发器保护。

## ADR-004 — 无 Docker 时使用隔离真实 PostgreSQL 验证

本机缺少 Docker。使用测试范围内 Zonky Embedded PostgreSQL 启动真实 PG 17.11 进程，临时目录/随机端口，测试结束关闭。Compose 和 Testcontainers 同时保留；两者的测试结果分别记录，不能以本地 PG 证明容器构建成功。禁止 H2 代替。开发工具仅位于被忽略目录，不注册系统服务、不改系统 PATH。

## ADR-005 — 版本锁定和开发运行时

Java21 已存在 D:/Java21，仅在项目命令进程设置 JAVA_HOME；CI/Docker 统一21。Node 本机25可执行，CI/容器选择24 LTS；npm 锁定依赖。版本已核对官方兼容说明和制品元数据。依赖升级需复跑门禁，不用浮动 latest。

## ADR-006 — P0 可见功能限于真实系统状态

状态页请求真实 MyBatis / PostgreSQL 健康接口；失败可重试，显示工程阶段和 AI 未接入。技能、图谱、学习等入口在对应阶段实现，不添加假数据卡片。P0 报告区分代码完成、测试通过和环境验收待验证。

## ADR-007 — GraphFlow 环境限制

已读取 GraphFlow 技能并查询会话工具列表，但工具未暴露，无法调用 context/plan/index。采用范围明确的文件操作并保留后续重建索引任务；不得称已完成图谱更新。未自动安装或改动用户全局 MCP 设置。

## ADR-008 — 测试依赖告警不使用跨主版本强制覆盖

npm审计发现Vue Test Utils的js-beautify → glob/minimatch/editorconfig开发依赖链中等级告警；`npm audit --omit=dev`生产依赖为0。保持锁定且能通过测试的上游版本，不执行`audit fix --force`或对glob强制跨主版本override，以免通过破坏兼容性隐藏告警。暂不处理不可信项目/任意glob输入；发布前复查上游修复。详细计数及边界在PROGRESS记录，不宣称全依赖无漏洞。

## ADR-009 — 干净环境依赖解析与构建缓存

容器构建实测发现MyBatis上游POM引入Sonatype快照/Spring里程碑仓库，在当前网络超时。项目仅使用已发布Central依赖，因此在backend/.mvn配置项目级Central镜像；不改用户全局settings。Docker用BuildKit缓存.m2。真实镜像构建及Testcontainers验证通过后关闭P0门禁。

## ADR-010 — 现有WSL2上的隔离容器验收

现成Ubuntu发行版可运行，无需重装Docker Desktop或启用系统虚拟化。官方Docker静态二进制与iptables依赖包只提取到专用缓存；进程、Unix socket、数据根和Compose项目独立，不注册系统服务。Windows代理只监听loopback，使用标准输入输出转发到WSL的loopback，未开放未认证Docker TCP API。Docker运行产生正常的临时桥接网络规则；不改持久系统网络配置。

Testcontainers在Maven容器内运行时传递TESTCONTAINERS_DOCKER_SOCKET_OVERRIDE为宿主机真实socket，供Ryuk清理资源；保持Ryuk启用。浏览器以PLAYWRIGHT_BASE_URL直接访问Nginx产物，保证包含构建输出和CSP验证。测试数据只在独立验收卷，不当作用户进度。

## ADR-011 — P1身份与管理员引导

JSON登录通过AuthenticationManager校验，显式轮换会话ID、CSRF并保存SecurityContext；Cookie不进入localStorage。Spring Session JDBC使用Flyway管理的官方表结构，不让框架自行建表。管理员邮箱/密码文件成对配置，只在users为空时创建，已有账号不重置；本地脚本通过SecureString输入、CreateNew写文件，不覆盖.env或已有秘密。测试账号仅位于隔离测试库。

采用BCrypt12与72 UTF-8字节上限，避免截断；登录限流10次/IP/5分钟，内存容量1000来源，过期回收，超限返回Retry-After。初期单用户单实例足够；P6再复核代理与分布式限流。认证DTO诊断字符串脱敏，覆盖本机DEBUG环境误开日志的已知情形。

## ADR-012 — P1手动图谱与一致性

节点定义、技能位置、关系分表。parent_node_id使用稳定知识节点UUID，通过同owner/skill的复合FK保证父节点属于当前技能；同节点在不同技能的位置独立。每次图写入先锁当前用户行，事务内检查分类环/全用户先修DAG并审计，避免同时添加相反边绕过校验。单用户低并发优先正确性，后续确有性能瓶颈再细化锁粒度。

技能/节点采用ACTIVE/ARCHIVED，保留引用与关系，恢复不换UUID；移出技能仅删除关联且拒绝遗留子节点，不静默丢弃节点。PATCH使用完整表单，不隐式清空缺失字段。前端创建定义和技能引用为两个显式步骤；引用失败时保留定义并提示通过节点库重试。客户端等待CSRF前冻结提交值，不自动重试写入。P1的CatalogService集中处理小型手动目录事务，P2再按版本发布边界拆分knowledge模块。

## ADR-013 — P2手动发布的保守一致性边界

knowledge模块独立管理草案/校验/发布。用户行锁串行化发布，revision保护草案，整个用户目录的稳定SHA256保护正式源；不自动合并过时草案。发布事务保留基础知识节点，只替换当前技能位置和内部关系；不可变快照保留历史。已有发布版本后，P1写接口不能绕过草案。共享定义不变允许引用，若会改变其他已发布技能内容则拒绝单技能发布，联合发布留给后续明确设计。预览保守列出所有引用技能，允许过度提示而不隐藏影响。

幂等键按用户唯一，与草案/revision/版本绑定。使用已有审计表保存草案变更和发布事件，不建立重复事实源。v1 Schema作为合同文件，严格Jackson/Bean Validation和图规则执行校验；AI Provider接入时还需完善通用Schema执行/异常输出恢复，当前不声称AI已实现。E2E共用一个验收账号，设单worker避免两个旅程互相触发正确的源指纹冲突；后端并发测试仍保留。

## ADR-014 — Provider传输先于生成入口

沿用Java21 HttpClient和现有Jackson，不引入Node运行时或供应商SDK。首个适配器实现Chat Completions结构化输出；网络调用不持有业务事务、不写正式图谱。默认禁用且无生成API，预算/任务落库完成前不开启浏览器调用。重试默认0，仅明确429/502/503可在整体deadline内有限重试；超时/断连不自动重复收费不明确的请求。用量缺失记UNKNOWN，不伪造估算或成本。当前仅本地HTTP协议测试，无供应商付费调用。流式/图片能力按后续阶段真实实现，不增加占位返回。

## ADR-015 — 同步任务与保守token账本

先持久化任务及独立草案，再在事务外调用Provider，最后事务结算和保存候选。使用UTC日token账本和已有用户行锁，按所有者+幂等键阻止重复请求；未知计费保留预留额度，进程崩溃不自动释放或重发。仅明确NOT_CONFIGURED释放。实际用量超出预留仍记录实际值，不以预算数字掩盖支出。token配额不是货币预算；货币策略、恢复和Schema兼容完成前不公开生成API。本轮无新队列服务、后台调度或付费调用。

## ADR-016 — 明确确认的中断任务结束

不用进程内状态推断重启前请求是否计费。数据库创建时间超过五分钟后，用户可确认将RUNNING转为FAILED/UNKNOWN，预留转保守消耗，不自动释放或重发。用户行锁串行化恢复与结果落库；终态任务忽略迟到结果，不覆盖草案。已结束任务重复确认无新增结算。查询API仅返回本人任务的状态及用量，省略输入hash/幂等键；页面使用手动刷新，暂不增加轮询和后台服务。货币对账与生成入口另行实现。

## ADR-017 — 可追溯价格快照与货币账本

V6以owner/UTC日/币种维护货币账本，费用按任务保存provider/model/价格版本日期/输入输出费率，改配置不重算旧任务。BigDecimal计算费用，向上取8位小数；只称配置价格下的计算值，不冒充账单。未知用量按预留占用，已知超额如实记账并限制后续请求，不隐瞒超额或承诺供应商硬上限。服务端设置价格和单次预留，不接受浏览器传费率。真实Provider启用须有货币策略且重试为0，逐次计费完成前避免漏算重试费用。无外部价格查询、实际模型调用或生产部署。

## ADR-018 — 内置Schema子集和显式生成开关

供应商Schema只转换内置v1合同：required全属性、禁止额外属性、可空父节点、const改enum；UUID/长度/范围和图语义继续由GraphValidator执行。不是通用Schema引擎。实际HTTP请求和token估计复用同一序列化；UTF-8字节+4096开销+8192输出作为保守估计，不承诺精确分词。生成API只接收主题和幂等键，配置模型及token/货币策略均留在服务端；generation-enabled与Provider开关同时有效且有token额度才显示可用。关闭时明确503且不写任务，页面保留手动流程。真实调用及生产部署仍需授权。

## ADR-019 — 独立启用协议验收套件

使用测试源集HTTP协议服务，调用真正Provider适配器和PG，不替换生产Provider或绕过请求/预算/事务。确定性数据仅用于验收，不宣称模型能力。启用浏览器套件通过显式环境变量选择独立文件；默认4项关闭配置旅程保留，不通过跳过测试混淆结果。临时运行时主动关闭应用/协议服务/PG并删除密码元数据，避免真实Key或学习数据进入测试。

## ADR-020 — P2编辑、联合版本与有限修复

不修改原V1合同，人工转换生成V2来源快照；节点定义保留，撤销连同映射回退，历史证据不自动重新归属。通过networknt 1.5.9执行固定JSON Schema 2020-12，再检查业务图/所有权，保留类型强约束。供应商仍只输出V1，拒绝伪造人工来源的V2。

共享定义修改可显式联合发布，先重新预览再确认；用户锁和单事务给实际受影响的已发布技能追加版本，不改旧版本或其他草案。故障注入验证跨技能回滚与幂等。

V7为失败恢复保留私有主题/修复上下文，仅服务器读取，任务API不返回、日志不记录、无Key入库；这是对旧版仅保存输入hash的明确更新。每父任务唯一子任务、最大depth2，只在用户确认后执行已知结构错误修复，每次独立预留预算。未知费用失败不自动重发。模型账单/质量不由测试协议代替，真实调用需先授权。

## ADR-021 — 显式DeepSeek JSON协议

DeepSeek Chat文档仅声明JSON对象模式，故增加显式`deepseek-json`配置，保留默认严格`json-schema`协议；没有自动降级或失败后重发。JSON模式在系统提示携带Schema，关闭默认思考、限制输出8192 tokens；响应仍须通过原有Schema/图验证才入草案。费用估计与传输复用序列化，避免漏计提示中Schema。无需更换框架、数据库或引入依赖。

用户授权一次V4.1 Flash真实验收、预算1 CNY；官方API ID使用`deepseek-flash`。采用官方人民币高峰未命中费率输入2元/百万、输出8元/百万保守计算；不套用缓存折扣，不冒充最终账单。独立临时PG、本机随机端口、单次哨兵文件防重复，无自动修复或重试。配置中的真实Key迁至Git忽略的本地文件，模板中清空Key，保留其他用户配置。参考[官方人民币价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)，核对日期2026-11-15。

## ADR-022 — P3不可变路线与可恢复学习记录

路线修订追加不可变的关系表版本，保留阶段、节点标题快照及旧选择；不自动迁移进度或历史。用户可重新选择旧版本，任务继续指向创建时的路线。进度按选择/路线节点自报，不冒充掌握度，已完成路线须重新选择才修改进度。初次进度/笔记PUT创建revision1，区分“尚不存在”的revision0并阻止并发初写覆盖。

沿用用户行锁串行化写入，时段仅服务器计时、毫秒分段累计；一个用户最多一个未结束时段，暂停也占此位置。同键同命令返回当前时段；不同命令409，操作记录追加且不可改。任务完成、路线已学、结束时段分别保存，避免隐式连带改写。资料是校验后的链接，不在服务端抓取；笔记纯文本显式保存，离开未保存笔记时提醒。首页继续任务独立过滤DOING/TODO，不受最近任务页截断影响。无新依赖、AI调用、队列或生产部署。

## ADR-023 — P4受控提示、证据与真实SSE

独立作答先持久化；严格一步提示来自已准备的提示，完整解析与导师请求需明确确认。开放式模型回复不保证严格不泄题，故不直接作为受限提示。证明/作品/图片默认UNSURE，人工复核和AI建议确认属于自报；规则文本比对与自评区分，规则最多L2，历史追加不覆盖。

沿用Java适配器实现Chat SSE，保留单体和原P2图谱合同，不引入AI SDK或付费服务。新导师运行表共享每日账本、预留/价格快照/UNKNOWN恢复；网络不占数据库事务、幂等重取仅snapshot。新增KaTeX精确锁定0.19.1，用于数学显示；按[安全文档](https://katex.org/docs/security)设置trust=false、扩展/尺寸上限，错误与其他输入纯文本显示。数学库按需加载，避免所有页面下载整库。

图片用JDK ImageIO做magic/尺寸/解码与PNG重编码，无新Java依赖。随机键、私有存储、鉴权下载，原件不公开、不自动发送模型。每用户默认256MiB配额，文件归档不释放物理空间；后续通过明确备份/清理流程处理。崩溃可能留下无DB引用的孤立文件，P6补清理；不把重新编码等同杀毒。Compose增加attachments-data私有持久卷，生产部署/模型实调用仍须单独授权。

## ADR-024 — P5确定性预算规则与确认计划快照

保持既有单体，无新增依赖。以P5交付/验收范围的每日任务为先，采用可解释的规则v1，暂不接入总纲3.4的AI内容文字增强，该项仍未实现、后续单独开发；页面明确规则来源，不能把规则输出称为模型建议。每日/技能预算约束预计分钟，整项选择、跨技能轮选；先修完成来自已有DONE任务或路线COMPLETED，不等同掌握验证。范围明确选择1..100技能，UI默认未选并限制列表显示高度，防止自动规划全部历史技能。

草案保存关系快照与源指纹，确认用用户行锁、源hash、revision、当天revision、明确确认和幂等键；不可变版本另存每日当前指针，避免借任务due_date保存计划并破坏截止日期。预算是预计用时约束，不是实际计时上限。当前/未来确认计划内任务不可直接改预计分钟，先取消相关计划再调整。确认/取消/任务变更均保留历史，不自动复制每天未完成积压。

指纹序列统一Java UUID排序，不能依赖PG ORDER BY UUID与Java自然顺序一致；数据库返回后再次归一化预算顺序，避免跨三技能误冲突。源指纹保守包含同用户先修关系/完成节点等上下文，其他活动可能使草案过期；不自动合并。候选超2000明确拒绝而非默默截断，确认最多200项。

## ADR-025 — P5稳定节点复习与新证据复测

每用户/节点一个安排，保留原任务与来源技能；可手动定首次日期，或初始证据正确3天/其余1天。存IANA时区与UTC时刻，所有日期由安排自身时区09:00转换。规则独立正确复测翻倍、最多365天，提示后正确、自评、错误或不确定均回1天；是保守启发式，不宣称记忆模型准确性。

复测必须使用安排建立或上次复测后的新作答、已确认同节点证据，证据不可重复使用；禁止反复确认旧答案刷间隔，不改掌握等级。每周期最多一个关联任务，仅在计划确认时创建，后续日复用；复测推进周期并结束旧周期任务，未结束计时须先处理。调度事件、周期关联与任务拆分记录追加不可变。延期/取消保留原记录，拆分须保总分钟；提前重新排期沿用P3工作台编辑与审计。

## ADR-026 — P6明确口径的分析与按需图表

真实时长只计已结束时段，整段按结束日归属，不重建跨日活动轨迹；任务按范围内创建/当前状态回看，取消单列。独立正确率只计独立作答且最新RULE明确对错；重复复核不能扩张分母，自评和UNSURE不混入。能力按节点/RULE/SELF分别取最近评估，提供原证据/练习追踪，不拼伪精确掌握百分比。聚合事务REPEATABLE_READ，IANA时区、最长366天和资源归属在服务器验证。

ECharts6.1.0从当前npm registry核实并精确锁定，用于总纲要求的趋势和技能投入图；SVG renderer、richText tooltip避免HTML注入，模块仅在分析页按需加载，清理resize observer/实例，保留数据表与空分母说明。新增图表包约546kB未gzip、186kB gzip，构建体积告警保留，不用调高门槛掩盖。

## ADR-027 — P6学习快照与知识目录迁移分离

学习快照是当前用户40表的只读结构化存档，限25000行/8MiB，不含身份凭据、会话、Key、审计事件、文件路径/二进制；不是可直接导入的全量备份。知识目录格式独立，严格解析最多2MiB，预览存服务器；明确确认、用户锁、revision/hash/幂等键、事务一次新增全部UUID，保留共享定义/位置/关系，不覆盖或合并旧知识。归档状态保留，不执行目录中的文本、URL或HTML。失败回滚全部新实体。

Jackson默认字符串转换不能仅靠ALLOW_COERCION_OF_SCALARS关闭，需要Textual显式拒绝Integer/Float/Boolean，并关闭ACCEPT_FLOAT_AS_INT、拒绝重复JSON键/未知字段。目录导入不包含学习/能力/附件，完整数据库与附件恢复、监控、生产安全继续作为P6未通过门禁，不能以目录迁移验收代替。


## ADR-028 — 配对备份与非覆盖隔离演练

短暂停止命名项目入口/后端，禁止活动计时和RUNNING模型任务时备份；pg_dump与附件共同校验、加密，finally恢复源服务。AES-CBC/PBKDF2加独立盐派生HMAC的encrypt-then-MAC先认证后解密，口令仅从私有文件读取；格式未经过独立密码学审计。恢复只生成新内部网络、容器/卷，不发布端口或传模型Key；比对全部表/UUID/文件与DB引用，再由新实例真实登录读取。只清理本次新建资源，不接受覆盖源数据库。Linux宿主内部桥访问已验证；原生Windows、跨PG版本、生产角色/TLS/会话撤销仍需独立方案。
