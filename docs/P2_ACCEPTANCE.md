# P2验收清单

核心功能已实现并通过最终本地验收：Windows/Linux各40项后端测试、9项前端单测、Nginx默认4项及启用协议2项浏览器测试。真实供应商与生成质量验收未执行，不提前将整个P2标记通过。P3–P6未开始。

| 总纲交付/验收 | 实现与证据 |
| --- | --- |
| 结构化AI草案 | 真实HTTP适配器、V1供应商Schema转换、默认关闭的生成API/UI；本地协议链路验收，非真实模型产出 |
| Schema/引用/重复/环 | 固定V1/V2执行Schema 2020-12，严格类型/UUID/所有权、全用户先修DAG和分类树；重复名称仅提示 |
| 草案增删改/移动/关系 | 节点与关系表单及高级JSON，独立保存，不随草案保存改变正式数据 |
| 合并/拆分/来源 | 保留目标或新UUID，V2记录原节点/目标映射及此前关系，不删除基础节点或自动迁移证据 |
| 撤销重做 | 有界会话历史，JSON与来源映射一起撤销，恢复后再保存 |
| 预览/确认 | 节点变化、关系数量、重复提示、跨技能影响；未确认不发布 |
| 发布/版本/回滚 | revision、源指纹、幂等键、不可变快照和审计；普通及联合发布故障注入回滚 |
| 跨技能修改 | 默认保护；明确选择联合范围并重新预览后，同事务给实际变化的技能追加版本 |
| 来源/时间 | 手动、AI候选、失败任务基础草案、联合发布来源与更新时间；历史版本发布时间 |
| 生成失败恢复 | 保留原草案/任务；已知结构失败可确认修复最多2次，各自新任务/预算；不自动重发超时/未知费用请求 |
| 无Key手动闭环 | 默认503且不写任务，手动编辑发布可用，Nginx桌面/手机回归 |
| Blender主题旅程 | 本地协议下生成→拆分→关系编辑→合并→撤销重做→重命名→发布→非法生成→修复；真实模型质量待验收 |

设计与复现见P2_DESIGN.md、AI_GENERATION.md、GENERATION_ACCEPTANCE.md，最终命令/结果见PROGRESS.md。本地协议响应仅在测试源集，不打包入生产，不能声称真实供应商/质量验收成功。

## 最终剩余门禁

真实供应商/模型、价格和Key尚未由用户安全配置，实际付费调用须按AGENTS.md先授权；不能使用本地测试数据替代这一步。未生产部署，货币预算为配置费率下的保守预留，不承诺供应商硬支出上限或实际账单对账。

拟执行的最后验收：独立临时PG和本机服务，主题为“Blender零基础：界面、建模、材质与渲染”，首次仅发一次结构化生成请求，不自动触发额外修复；核对来源/用量/费用，人工编辑后在隔离库发布及查看历史。需要用户指定真实服务地址/模型、价格依据、预算及币种，并在本地配置Key（不发送到聊天、不写日志、不提交Git）。不会发布公网或修改真实学习数据。授权后仍先检查预留是否覆盖请求估计，配置或预算不满足就不发请求。

流式导师、图像教学和能力证据迁移属于后续阶段；本轮保留节点定义及映射，不冒充这些功能。当前为表单/JSON编辑器，不声称拖拽画布或自动冲突合并。
