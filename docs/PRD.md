# 产品需求基线

需求依据：根目录正式总纲 v1.0（2026-11-15）。本文件是可追踪摘要，不替代总纲；出现冲突以总纲为准。

Scarlet Nexus 面向单用户私有部署，管理任意领域的终身学习。核心链路为技能 → 知识结构 → 目标 → 路线 → 任务 → 学习活动 → 证据 → 掌握评估 → 复习。首版不包含社交、交易、排行榜、原生 App、微服务。

| 需求 ID | 用户能力与约束 | 阶段 / 验收 |
| --- | --- | --- |
| R00 | 可复现启动、健康检查、真实持久化基础、安全默认值 | P0：前后端与 PostgreSQL 启动、Flyway / 测试通过 |
| R01 | 私有登录、技能与手动知识树、依赖、搜索、归档 | P1：创建 Java 技能及层级节点，刷新保留；越权 / 错误引用 / 环被拒绝 |
| R02 | AI 或人工草案、可编辑、变更摘要、确认发布与历史 | P2：Blender 草案编辑后发布；失败回滚、并发冲突可见 |
| R03 | 目标、路线、每日任务、学习记录、笔记和资料 | P3：中断再进入可恢复，无 AI Key 仍完整可用 |
| R04 | 节点导师、分级提示、练习、附件、证据与保守评估 | P4：先独立作答再提示；失败不丢作答，不确定可复核 |
| R05 | 时间预算下的计划草案、确认、延期与到期复习 | P5：11408 / Java / Blender 跨技能不超预算，未确认不改正式任务 |
| R06 | 分析、JSON 导入导出、备份恢复、生产准备 | P6：回归通过，恢复后记录和关联一致，移动端可用 |

导航：Dashboard、Skills、Knowledge、Paths、Study、Planner、Reviews、Analytics、Settings。首页到当前学习任务目标不超过三次点击。桌面侧栏，移动端可用导航及列表编辑，不要求完整拖拽。

不变规则：知识定义 / 路线 / 个人进度 / 对话分离；节点稳定 UUID；分类树与先修图都无环；同节点可跨技能引用；完成率与能力等级分开；L0–L5 评估关联证据，标明自评、可信度和最近验证时间；不生成虚假百分比。AI 不直接发布图谱、删除证据或决定掌握状态。

每个阶段的实际实现边界见PROGRESS；未到阶段的页面、端点和字段均是设计，不能视为已实现。P1已提供登录、技能空间和手动知识树及移动列表编辑；系统诊断在/system。没有真实学习时长、掌握度或AI草案时不展示假数据。
