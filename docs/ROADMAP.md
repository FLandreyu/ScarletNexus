# 分阶段路线与验收门禁

每阶段：先标准 → 真实实现 → 测试 → 人工可验收 → 更新进度 → Git 提交。最早未通过阶段优先，禁止跳过。P7 不自动启动。

当前P0–P3已验收，P3已完成无AI的目标→路线→任务→学习→笔记/资料→退出恢复与历史保留闭环。证据见PROGRESS/P3_ACCEPTANCE；下一步P4，P4之后均为计划。P2真实样例及其质量局限仍见P2_ACCEPTANCE。

| 阶段 | 交付范围 | 必须验收 |
| --- | --- | --- |
| P0 | 全套设计、工程、Compose、Flyway、健康、CI、README | 干净环境按 README 启动前端/后端/PG；迁移、格式、构建、单测、API集成；无密钥 |
| P1 | 引导管理员、登录退出、技能/节点/分类/依赖、搜索、移动浏览 | Java 技能树持久化；错误引用/分类环/依赖环拒绝；双用户隔离、CSRF、登录限流 |
| P2 | AIProvider、版本化 schema、草案编辑、撤销重做、变更预览、发布历史 | Blender 草案编辑发布；非法AI输出不污染数据；事务回滚；并发409；无Key可手动编辑发布 |
| P3 | 目标/路线/任务/学习时段/笔记/资源、继续学习 | 退出恢复、路线变更不损历史、无AI闭环、时段幂等 |
| P4 | SSE导师、KaTeX、图片附件、提示等级、练习与证据、规则评估 | 独立作答后提示；不确定可复核；附件隔离；AI超时不丢作答 |
| P5 | 预算规则、计划草案确认、延期、到期复习 | 三技能不超预算；未确认不覆盖；复测/调度原因可查 |
| P6 | 分析、导入导出、备份恢复、监控、生产说明、移动E2E | 全旅程、恢复完整性、登录/附件安全、无硬编码密钥；生产部署另行确认 |

P1 可执行顺序：身份和数据库会话 → 技能 CRUD/归档 → 稳定节点与跨技能引用 → 分类树与依赖环验证 → 搜索/移动界面 → 刷新持久化和双用户安全回归。验收未完成前不接入 AI 付费调用。
