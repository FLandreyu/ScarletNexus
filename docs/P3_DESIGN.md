# P3 学习目标、路线与学习记录

正式依据：总纲3.3、4.1、P3。沿用模块化单体、认证用户隔离、用户行锁与事务审计；无新依赖、付费调用或后台调度。

## 验收标准

1. 目标可创建/编辑/归档；选择本人的技能、截止日期和优先级，外来ID拒绝。
2. 路线包含阶段、稳定节点引用、顺序、目标等级和必修标记。修改追加不可变版本；旧选择、进度、任务和时段保留，过期版本编辑409。
3. 选择路线，按节点建立任务，标记学习状态，展示必修完成数量。目标等级是学习目标；进度是自报，不等于掌握度或证据。
4. 手动任务可更新状态/预计时长/截止日期；学习工作台展示节点、路线位置、先修与资料。没有AI配置也可完成学习闭环。
5. 学习时段支持开始、暂停、继续、结束；每用户只有一个未结束时段。服务器计时、毫秒累计、状态revision及幂等键防重复记时；退出/刷新后恢复同一时段。
6. 笔记明文持久化、乐观锁防覆盖；资料仅保存经过校验的http(s)链接，不抓取外部内容、不上传附件。归档保留历史。
7. 首页显示继续学习和任务；退出登录再进入，记录恢复。真实PG迁移/API验证所有权、并发、幂等、路线历史；桌面/手机浏览器走完整手动学习流程。

## 数据与行为

V8新增目标、路线/阶段/节点、路线选择、节点进度、任务、时段/幂等操作、笔记、资源/节点关联。核心关系使用列与复合FK；不修改V1–V7。所有私有查询按当前用户，写入持有用户行锁，版本/状态保存检查revision。所有ID为UUID、时刻为UTC timestamptz；任务截止日期为日历date。

路线版本使用family_id + version_number。阶段/节点不可变，保存标题快照；修订需要基于该族最新版本，不自动迁移学习记录。选择新路线暂停此前选择，不结束正在进行的学习时段。进度按选择+路线节点隔离；旧路线仍能查看、继续或恢复选择。

任务可关联目标、路线选择及路线节点；引用必须同一用户、技能及路线。任务完成不自动认定节点掌握，也不自动结束计时。工作台分别提供结束时段和标记完成，避免隐式改写。

时段始终关联任务；同一任务可多次学习。计时分段存服务器起点及累计毫秒，客户端仅展示；幂等键重复相同命令返回当前时段，不重复累计，不同命令返回409。暂停/结束使用revision，结束后不可重开。浏览器离开时运行中的计时继续，用户应暂停；不把页面在线时长当作专注检测。

笔记按任务保存（节点稳定引用经任务保留），纯文本显示，修订审计。资料与节点关联、可归档；不在服务端下载链接，不支持附件或AI导师（P4）。列表按页读取，路线每版最多30阶段/300节点。

## 接口与页面

API前缀`/api/v1/learning`：goals、paths、enrollments、progress、tasks、sessions、notes、resources、dashboard。读历史不受技能归档影响；新目标/路线/任务要求可用技能节点，暂停/结束历史时段不依赖目录当前位置。

前端`/learn`为首页/继续学习与任务；`/paths`管理目标和路线；`/study/:id`为任务工作台。保留现有技能入口，技能页增加前往学习路线链接。表单/列表提供手机替代，不引入拖拽画布。
